# 🧮 Simple Calculator - C#

A simple console-based calculator application built using **C#**. This project allows users to perform basic arithmetic operations through the console and repeat calculations as needed.

## 📌 About The Project

The Simple Calculator is a beginner-friendly C# console application created to practice fundamental programming concepts.

The program takes two numbers from the user, asks for an arithmetic operator, and displays the calculation result.

Users can perform multiple calculations until they choose to exit.

## ✨ Features

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* User input through the console
* Continuous calculation loop
* Operator selection using a switch statement
* Basic input validation for operators
* Option to continue or exit the program

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* .NET SDK
* Visual Studio or Visual Studio Code

### Installation

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/simple-calculator-csharp.git
```

2. Navigate to the project folder:

```bash
cd simple-calculator-csharp
```

3. Run the application:

```bash
dotnet run
```

## 💻 How To Use

1. Run the program.
2. Enter the first number.
3. Enter the second number.
4. Choose an operator: `+`, `-`, `*`, or `/`.
5. View the calculation result.
6. Choose whether to continue or exit.
